## 開始遊玩

1. 將 ZIP 完整解壓縮到獨立資料夾，保留所有檔案。
2. 開啟 `LingjingExpeditionLauncher.exe`；之後都使用此啟動器檢查更新並進入遊戲。
3. 首次登入或註冊請保持網路連線，並使用自己的帳號。不要只移動單一 EXE。

已有啟動器修正版的玩家，關閉遊戲後重新開啟啟動器即可檢查更新。直接開啟 `Game/LingjingExpedition.exe` 會略過更新檢查。

完整 Launcher 玩家包可以從 GitHub 下載，也可以由朋友透過 Google 雲端硬碟分享；請完整解壓縮並開啟 `LingjingExpeditionLauncher.exe`，才能檢查更新。直接開啟 `Game/LingjingExpedition.exe` 會略過更新。舊的獨立合作測試包 `LingjingExpedition-Coop-Windows-20261008-123903.zip` 不含啟動器，重開遊戲不會自動更新；請改用完整 Launcher 玩家包。

啟動器更新時會保留本機「遊玩紀錄」與帳號進度。更換整個安裝資料夾前，請備份 `Game/遊玩紀錄`。

## 啟動器 2.0.0：差異更新

最新版完整玩家包包含遊戲 1.2.7 與啟動器 2.0.0。啟動器視窗會顯示版本 2.0.0；遊戲首頁顯示遊戲版本 1.2.7。

已有啟動器 2.0.0 的玩家可重新開啟啟動器取得 1.2.7 更新；首次遊玩的玩家請下載並完整解壓縮新版玩家包。有符合目前安裝版本的差異包時，只下載新增／修改的檔案；已刪除的舊遊戲檔會移除，遊玩紀錄及帳號進度保留。Unity 合併的大型資源檔有變動時，仍需下載整個該檔案。

沒有對應差異包或本機可重用檔案損壞時，啟動器會使用完整更新包。下載中斷會有限次重試；驗證失敗則保留舊版。已是最新版時不會重新下載。

## 目前版本：1.2.7

多人合作現在會讓所有玩家看到各角色的 Q／E 技能特效。清敵後走進唯一的關卡門，才會前往下一關；目前門直通下一個戰鬥關卡。合作一般敵人血量減半，原始槍可開鏡。保留非房主傷害數字、F 鍵 3 秒救援及 1-1 至 1-5 關卡。

**要自動更新，請從完整包根目錄開啟 `LingjingExpeditionLauncher.exe`。直接開啟 `Game/LingjingExpedition.exe` 只會執行已安裝的遊戲，不會檢查更新。**

從 GitHub 或 Google 雲端硬碟取得同一份完整 Launcher ZIP，更新方式相同。仍使用 1.2.3 完整包的玩家，也可透過根目錄的啟動器檢查最新版本；更新完成後，首頁會顯示目前遊戲版本。

所有合作玩家都需更新至 1.2.7 並重新開房；本版使用 protocol 6，無法與舊版本連線。

### 大廳與合作功能

保留大廳鍵盤快捷鍵與 **2～4 人合作 1-1 至 1-5**。一般單人冒險仍可從大廳兩扇 AI 門進入。

### 大廳快捷鍵

選好角色後，可直接按鍵開啟功能，不必先按 ESC 切換滑鼠。

| 按鍵 | 功能 |
| --- | --- |
| C | 重新選角 |
| O | 切換大廳俯視／角色視角 |
| P | 多人合作 |
| M | 管理者 |
| L | 飲水機 |
| G | 武器商店 |
| B | 敵人／武器圖鑑 |
| H | 帳號主畫面 |

原有 `V` 第一／第三人稱、`W/A/S/D` 移動、`Q/E` 技能、`R` 換彈與 `F` 互動等操作維持原設定。管理者功能依帳號權限開放。

### 和朋友合作

每位玩家先更新至 1.2.7、登入並選角，再按「多人合作 (P)」。

- **同一 Wi-Fi／手機熱點**：選「區域網路 LAN」。房主開房，隊友搜尋房間加入；也可輸入房主 IPv4 與 6 位數字房號。
- **不同地點**：選「網際網路 Relay」。房主開房並分享 Relay 房間代碼，隊友輸入代碼加入。
- 至少 2 人加入後，由房主按「開始合作 1-1」。最多 4 人；房主離開會結束本次合作。

合作可移動、跳躍、使用原始槍／刀／盾、攻擊、換彈，並由每位玩家施放自己所選角色的 Q／E 技能。清除敵人後會出現通往下一關的門，走進門才會前進；通過 1-5 為勝利。存活玩家靠近倒下的隊友按 F 可開始救援；原地持續 3 秒後復活，移動或攻擊會中斷。原始槍可按滑鼠右鍵開鏡並用滾輪調整 2／3／4 倍，開鏡射擊造成 2 倍傷害；擴充武器尚未開放。合作不寫入單人冒險進度、AI 配對研究紀錄或大廳金幣。

LAN 不使用 Relay 流量，也不會自動切換成 Relay。本次更新沒有啟用付費方案；Relay 使用量仍受 Unity 專案方案與服務額度限制。

部分手機熱點會隔離連線設備，可能無法使用 LAN。連線排查與 AI 配對第二場期間的限制，請見 [遊玩說明](遊玩說明.txt)。

## 單人研究紀錄

單人模式每通過一大關（1-6、2-6、3-6）即保存一場大關紀錄；通過第一大關後，可返回主畫面並確認進入另一扇 AI 門，進行另一種模式的配對遊玩。

研究紀錄不會自動上傳。遊玩完畢並關閉遊戲後，請將整個 `Game/遊玩紀錄` 資料夾壓縮成 ZIP，再傳給開發者。完整操作、備援位置與紀錄回傳方式請見 [遊玩說明](遊玩說明.txt)。
