# 靈境遠征

《靈境遠征》Windows 遊戲下載與自動更新。

## 下載遊戲

- [下載完整 Windows 玩家包](https://github.com/cuiminrui/LingjingExpedition-Downloads/releases/latest/download/LingjingExpedition-Launcher-Windows.zip)
- [最新版本與更新說明](https://github.com/cuiminrui/LingjingExpedition-Downloads/releases/latest)

## 開始遊玩

1. 將 ZIP 完整解壓縮到獨立資料夾。
2. 開啟 `LingjingExpeditionLauncher.exe`；之後都使用此啟動器檢查更新並進入遊戲。
3. 首次登入或註冊請保持網路連線。請保留整個資料夾，不要只移動單一 EXE。

啟動器更新遊戲時會保留本機「遊玩紀錄」與帳號進度。更換整個安裝資料夾前，請備份 `Game/遊玩紀錄`。
