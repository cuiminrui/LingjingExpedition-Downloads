## 本版更新

- 從空中的動力滑翔機離座後，會立即自動開傘；保留離座位置與水平慣性，地面下機仍為正常下車。
- 更新大逃殺地圖、湖泊、房屋地基與邊坡，以及地圖顯示和管理者標記瞬移。
- 更新敞篷車、機車、越野車、汽艇與動力滑翔機外觀，調整物資與 Bot 交戰節奏。
- 修正趴下／倒地身體命中與死亡戰利品呈現，加入跳傘風聲及涉水噴濺。

單人冒險、多人合作、香韻菜園等既有內容保留。

## 開始遊玩

1. 將 ZIP 完整解壓縮到獨立資料夾，保留所有檔案。
2. 開啟根目錄的 `LingjingExpeditionLauncher.exe`。
3. 登入或註冊時保持網路連線，並使用自己的帳號。
4. 之後從同一個啟動器檢查更新並進入遊戲。

不要只移動單一 EXE。直接執行 `Game/LingjingExpedition.exe` 會略過更新檢查。

## 已有玩家更新

先關閉遊戲，再重新開啟啟動器檢查更新。本版沒有對應目前安裝內容的差異包時，會下載完整遊戲更新包。下載完成並通過驗證後才替換遊戲；多人玩家請全部更新至 1.2.16 後再開房。

完整玩家包從 GitHub 下載或由朋友分享，更新方式相同。更新會保留本機 `Game/遊玩紀錄`；更換整個安裝資料夾前，請先備份該資料夾。

遊戲更新包也附有啟動器升級檔。舊啟動器的玩家若在遊戲畫面設定看到「更新啟動器並離開遊戲」，可依畫面操作升級；也可重新下載完整玩家包。

## 遊玩與連線

大逃殺可從遊戲內選擇單人或房間模式。多人合作支援 2～4 人，包含合作冒險與勝利慶典。每位玩家須使用自己的帳號及相同遊戲版本。

區域網路與網際網路 Relay 依遊戲內房間選項操作；Relay 與房間語音需要可用的網路及相關服務。房主離開會影響該房間的遊戲。

完整操作與研究紀錄說明，請見玩家包內的 `Game/遊玩說明.txt`。
